# 外部レビュー依頼: Enigma (3v3 MOBA) — RL学習・バランス測定・Bot AI・マップ設計

これは外部レビュアー(ChatGPT 等)向けの自己完結型ブリーフです。リポジトリを読まなくてもレビューできるよう、設計判断・実測データ・既知の問題をまとめています。**「うまくいっている」と我々が信じている部分こそ疑ってください。** 各節末尾に特に聞きたい質問があります。

## プロジェクト概要

- **Enigma**: Fantasy×SF の 3v3 3D MOBA(Smite 風 TPS 視点)。Unity 6.3 / URP、ソロ開発
- マップ「Aether Rift」: 上から見ると目(アーモンド)形。2つの円弧(中心(0,∓48), R=120)の交差領域。目尻±110、z±72
- キャラ6体(rin=遠隔マークスマン、zeph=遠隔メイジ、nova=遠隔サポート、garon=タンク、veil=近接アサシン、thorne=近接ブルーザー)
- Bot は全役職スクリプトAI(後述)。ML-Agents による強化学習は一時停止中(後述)
- 開発プロセス: 変更→100試合の自動シミュレーション→統計→次の変更、の反復
- **注意(最重要)**: 現在の Bot 試合は自然決着がほぼ発生せず、15分時点の優勢判定を勝敗の**暫定プロキシ**としている。これはバランス測定上の最大リスクであり、製品仕様として確定したものではない
- **最重要質問**: この OT 優勢プロキシでキャラ調整を続ける場合、どこまで実ゲームのバランス判断に使えるか、どこから先は人間プレイ/別指標が必要になるかを重点的にレビューしてほしい

## 1. 強化学習(ML-Agents)の環境設計と再開計画

### やったこと
1v1 の戦闘ミクロ(カイト・間合い管理)を PPO で学習。**環境設計の失敗を5回反復**:

| Run | 構成 | 結末 | 診断 |
|---|---|---|---|
| v0 | 対称 self-play、時間ペナルティ | 相互回避(報酬-1.5固定/分散0) | 逃げ切りが敗北より得 |
| v1 | +交戦シェーピング+引分罰 | 棒立ち相打ち | 対称+回避不能攻撃では移動に因果がない |
| v2 | 非対称(遠隔学習者 vs 速い近接) | -2.35で平坦 | 速い追跡者=必ず捕まる=最善手でも敗北で勾配消滅 |
| v3 | 速度対等・追跡者HP増 | 分散0.000 | 固定スポーン×決定論的相手=全エピソード同一 |
| v4 | +スポーンランダム化 | 分散0.037 | 死亡罰の定数項が支配し生存差が報酬に出ない |
| v5 | 生存+0.0005/step、二重死亡罰廃止 | 報酬曲線上は改善(-0.41→-0.32, 1.5M steps) | 学習は進んだが、採用評価では手書きAI未満(下記) |

- 観測11次元(自他HP率、attackReady、距離、方向、位置オフセット、CD)/行動は連続2次元(移動)
- **評価(B3)**: 共通の対戦相手(スクリプトの近接チェイサー)に対して、手書きAI と 学習済み ONNX を**別々に**各~100エピソード測定(head-to-head ではない)。エピソードはどちらかの死亡まで続くため引き分けなし → **手書き 44% / 学習AI 36%**(足して100%にならないのは別測定のため)。95%CI は各±10pp 程度。採用基準(手書き超え)未達で本採用見送り。「報酬が改善した」ことと「採用に足る性能」は別条件として扱っている
- **再開計画**: 手書きAIのプレイを Demonstration Recorder で採取し、BC(behavioral_cloning)+GAIL で模倣 → PPO 微調整、のウォームスタート方式

## 2. バランス測定の方法論

### 仕組み
- **BalanceSimRunner**: エディタ上で 3v3 Bot 試合を timeScale=10 で100試合連続実行(実時間~2.8h)。1試合1行の JSONL(勝敗・試合長・キャラ別K/D/CS・タワー/キル時刻・コア討伐)
- ロースター: 6キャラを毎試合シャッフルして3v3に割当(グローバル重複なし=全キャラ毎試合出場、n=100/キャラ)
- **勝敗の暫定プロキシ**: Bot 試合は15分のオーバータイム(OT)減衰(全構造物が毎秒最大HPの1%を失う)までほぼ決着しないため、**「OT突入時点(900s)の優勢(生存タワー数→構造物残HP→乱数)で勝者を決める」**を Bot 測定上のプロキシとして採用している(製品仕様は別判断)。firstTower→勝利の相関は82〜97%。このプロキシは「敵本陣を壊す能力」でなく「15分時点の盤面優勢」を測るため、ポーク/ファーム型を過大評価するバイアスが疑われる
- **検証ガードレール候補(未実装)**: Botバージョン固定、同一シード新旧比較(CRN)、Blue/Redミラー、単純Bot/ランダムBotとの対照群、主要パッチごとの人間観察チェック
- 運用制約: 1イテレーション最大3キャラ・各値±10%・characters.json のみ変更・1イテレーション=1コミット

### 実測と学び
- 4イテレーションで勝率スプレッド 35-73% → 39-59% に収束(rin 73→57%)
- **n=100 の測定ノイズは±5pp(暫定観測)**: 無変更キャラが±5pp 動く一方、±10%のステータス変更の効果はそれ未満 → ステータス微調整を凍結。全キャラ毎試合出場のため勝率は独立でなく、正式にはペア比較/CRN/ブートストラップ等で扱うべき(未実装)
- クラス効果が最強のシグナル: 遠隔ファーム型(nova/rin/zeph)>50%>近接(veil/garon/thorne)。対策として近接に対構造物ダメージ×1.5 を付与(効果は限定的: OT前に落ちるタワーが全体の11%しかないため)
- 発見した系統的問題: タワー射程11 vs AA射程15 の「無償ポーク」がメタを支配(→タワー射程16に)、OT減衰同時死のタイブレークが反復順で常に片側勝利(→スナップショット判定に修正)
- 未解決の非対称: 先制キルは Blue 64%、先制タワーは Red 59%(チーム勝率自体は 42-60% で揺れており固定バイアスなし)

### 質問(2)
- OT優勢プロキシでキャラ勝率をバランス指標に使うのは統計的に妥当か? 歪み(ファーム偏重メタの固定化など)への対処は?
- 全キャラが毎試合出場する設計では勝率が独立でない(6キャラの勝率和=300%)。この相関構造での有意差判定の正しいやり方は?
- ±5pp ノイズ問題への現実解: 試合数を増やす以外に、ペア比較・レーティング(Elo/TrueSkill)・分散低減(CRN: 同一シードで新旧を比較)等は有効か?
- 先制キル Blue 64% / 先制タワー Red 59% の非対称を切り分ける実験設計は?

## 3. Bot AI(スクリプト)の構造

### 構造
- 純C#の判断ロジック(EditModeテスト付き)+MonoBehaviour は実行のみ(humble object)
- **マクロ優先順位**: Retreat(低HP+劣勢) > Defend(自陣タワー被弾) > GroupForObjective(中央コア) > CloseOutSiege(優勢時の攻城集合) > Push > Defend(予防) > Farm
- 優勢判定: タワー損失差≥1 **or** チームキル差≥3
- コア(中央ボス、HP1000、討伐でチームバフ)へのコミット: ボスHP<60% or 味方2人がボス近傍 → 敵接近でも離脱せずスキル解禁
- アンチデッドロック: GroupForObjective 選択後20秒エンゲージ圏未到達 → 30秒間選択禁止
- ミクロ(交戦中の移動)は別モジュール(CombatMicroModel: カイト・ストレイフ・フォーカス選択)

### 実測した失敗と対処
- **全ゲームデッドロック**: コア集合条件を緩和(参加圏63m・頭数緩和)したら全6Botが永久にコア集合を選び、キルが開始100秒以降ゼロに。→ 緩和巻き戻し+距離ゲート+ギブアップ機構
- **サイレント棒立ち**: 「攻撃してよい」判定は通るのに攻撃実行関数が射程外で無言return+直後にその場停止 → 近接がボスの手前で永久静止。→ 射程外なら接近するよう修正
- 結果: コア討伐が 300試合ゼロ → 直近は0.8回/試合まで改善
- 未解決: 全試合が OT までもつれる(自然決着ゼロ。タワー射程16で攻城が重い)、ジャングラーの消極性

### 質問(3)
- この優先順位ラダー方式の限界と、次の一手(ユーティリティAI、ビヘイビアツリー、GOAP等)への移行判断基準は?
- 「全員が同じマクロ選択に吸われて崩壊」を設計段階で防ぐパターン(役割分担、コミットメント、票割れ)は?
- 自然決着ゼロ問題: タワー射程を守ったまま「試合を閉じる」ための定石(ミニオン成長、デスタイマー逓増、勢い報酬)のうち、Bot 環境で最も副作用が小さいのは?

## 4. マップ設計

### 構成(LoL サモナーズリフトの設計思想をリスペクト)
- **同心構造**: 中央クレーター(すり鉢、底r14・y-2.5、コア鎮座)→ ジャングル(r22〜54、迷路壁+川y-1.2+高台ブロブy+1.5)→ 円環レーン(r56〜70)→ 外周壁(r70.5〜72、基地正面±30°のみ開放)→ 基地(タイタン±82、プラトーy+2.5にリスポーン)
- **壁の開口**: ジャングルパス口±8°(対角4本)、川口±13°、ガンク口±3°(タワー間からジャングルへ)。基地正面は封鎖(タイタンへの全導線がタワー圏経由)
- **迷路**(2段階): 弧壁(r38-41.5系+内周 r28-31.5系)+放射チョーク(r42-54)。回廊幅≥6.5m。回廊の行き止まりにジャングルキャンプ(計10箇所12体、リーシュ付き)
- **視界2.0**: 基礎=距離FoW。その上に追加遮蔽ルール3つ: 茂み12ゾーン(同じ茂みに敵視界源が無ければ不可視)/高低差(1m超上は不可視、上から下は可視)/地形遮蔽LoS(壁+地形メッシュへのレイキャスト)
- タワー: 各レーン2基(外600/内800HP)、射程16(全AAをアウトレンジ)、0.45sチャージ予兆つき回避可能弾
- コア: 討伐でチームバフ(1回目+25%与ダメ/60s、2回目+移速、3回目以降+対構造物×2)、リスポーンあり

### 時間スケール(判断材料)
- 移動速度 5.5〜6.0 m/s(全キャラ)。リスポーン5秒
- 基地(泉)→最寄りレーン: 約6〜8秒/基地→中央コア: 約18秒/レーン外周1/4周: 約17秒/マップ横断(240m): 約40秒
- 視界(距離FoW)半径: チャンプ約22m・ミニオン約10m・タワー約16m
