# Task 26: External Review Brief Report

対象: `codex-tasks/26-external-review-brief.md`

## Summary

外部レビュー依頼としての構成は良好です。失敗履歴、実測値、未解決問題、レビュアーへの質問がまとまっており、リポジトリを読まない第三者でも議論に入れる形になっています。

ただし、現状のブリーフは「Botシミュレーションで測れたもの」をそのまま「ゲームとしての強さ・健全性」に接続して読む危険があります。特に `OT時点の優勢=勝敗` と `自然決着ゼロ` は、バランス指標の土台そのものに関わるため、外部レビュー前により強く警戒扱いにした方が安全です。

## Findings

### P1: OT時点の優勢を正式勝敗として扱うと、バランス測定が別ゲームを最適化する

`OT突入時点(900s)の優勢` を勝敗仕様として受け入れている一方、同じ文書内で `自然決着ゼロ` が未解決とされています。

- 対象: `codex-tasks/26-external-review-brief.md:46`, `codex-tasks/26-external-review-brief.md:78`
- リスク: キャラ勝率が「敵本陣を壊す能力」ではなく「15分時点でタワー/構造物HPを多く残す能力」を測る指標になる。
- 影響: 遠隔ファーム型、ポーク、守備的な構成が過大評価され、攻城・集団戦・終盤決着力が過小評価される可能性がある。
- 提案: 本文では `正式仕様として受け入れた` よりも、`Bot測定上の暫定プロキシとして採用している` と明記する。製品仕様として本当に採用するかは別判断に切り分ける。

### P1: Botの既知バグ/行動欠陥を、キャラバランス差として読んでしまう恐れがある

バランス測定は 3v3 Bot 試合に依存していますが、Bot側にはコア集合デッドロック、サイレント棒立ち、ジャングラー消極性、自然決着ゼロが既知問題として残っています。

- 対象: `codex-tasks/26-external-review-brief.md:44`, `codex-tasks/26-external-review-brief.md:74-78`
- リスク: 実装と検証が同じ盲点を共有し、Botの癖をキャラ性能として誤認する。
- 影響: 近接が弱い、遠隔が強い、コアが効く/効かない、といった結論が、キャラ性能ではなくBot意思決定の偏りに由来している可能性が残る。
- 提案: ブリーフに `Botバージョン固定`, `左右ミラー`, `同一シード新旧比較`, `単純Bot/ランダムBotとの対照群`, `人間プレイ観察との差分` を検証ガードレールとして追記する。

### P1: 「学習成立」という表現が採用評価と矛盾して見える

v5 は `学習成立` と表現されていますが、その後の採用評価では `学習AI 36% vs 手書き 44%` で未達です。

- 対象: `codex-tasks/26-external-review-brief.md:27`, `codex-tasks/26-external-review-brief.md:30`
- リスク: 報酬改善を性能改善と誤読される。
- 影響: 外部レビュアーが「学習は成功している前提」で議論し、評価設計や報酬設計の問題を見落とす可能性がある。
- 提案: `学習成立` は `報酬曲線上は学習が進んだが、手書きAIには未達` に弱める。成功条件を `報酬改善`, `勝率改善`, `手書きAI超え`, `人間観察で自然` に分離する。

### P2: 36% vs 44% の評価内訳が不足している

学習AIと手書きAIの比較が合計100%になっておらず、引き分け、タイムアウト、無効試合、その他結果の扱いが読み取れません。

- 対象: `codex-tasks/26-external-review-brief.md:30`
- リスク: 勝率差の意味、統計的不確実性、評価環境の安定性を判断できない。
- 提案: 試合数、勝敗/引分/無効の内訳、95% CI、評価シード、スポーン分布、同一初期条件での役割入れ替え結果を追記する。

### P2: n=100 の ±5pp ノイズを単純な勝率変動として扱うのは危うい

全キャラが毎試合出場する設計では、キャラ勝率は独立ではありません。本文でも質問に入っていますが、実測と学びの節では `±5pp` を比較的素直な測定ノイズとして扱っています。

- 対象: `codex-tasks/26-external-review-brief.md:45`, `codex-tasks/26-external-review-brief.md:51`, `codex-tasks/26-external-review-brief.md:58`
- リスク: 有意差のない変動をバランス改善/悪化として扱う。
- 提案: `±5pp` は暫定観測と書き、正式にはペア比較、CRN、ブートストラップ、階層モデル、またはTrueSkill/Elo系の補助指標で扱う方針を足す。

### P2: マップ寸法の評価に必要な時間スケールが足りない

`直径240m`, `レーン1周~400m` は提示されていますが、移動速度や到達時間がないため、外部レビュアーは広さを判断しづらいです。

- 対象: `codex-tasks/26-external-review-brief.md:90`, `codex-tasks/26-external-review-brief.md:98`
- 足したい情報: 平均移動速度、基地からレーン復帰までの秒数、基地からコアまでの秒数、外周1/4周の秒数、視界距離、平均交戦開始時刻、死亡復帰時間。
- 提案: 距離ではなく `何秒で戻れる/寄れる/逃げられるか` を併記する。

### P3: 視界2.0の要素数が記述と一致していない

質問では `3ルール(茂み/高低差/LoS)` としていますが、構成では `距離FoW + 茂み + 高低差 + LoS` の4要素に見えます。

- 対象: `codex-tasks/26-external-review-brief.md:93`, `codex-tasks/26-external-review-brief.md:100`
- リスク: 小さいが、外部レビュアーの認知負荷が上がる。
- 提案: `距離FoWを基礎条件、追加遮蔽ルールは3つ` など、分類を明確化する。

## Recommended Additions Before External Review

1. `OT勝敗は暫定プロキシであり、自然決着ゼロが最重要未解決リスク` と冒頭サマリに書く。
2. Bot測定のガードレールを明記する。最低限、左右ミラー、同一シード比較、Botバージョン固定、対照Botを入れる。
3. RL節では `報酬上の学習成立` と `採用性能未達` を分離する。
4. 評価結果には試合数、引き分け、無効、信頼区間、シード条件を足す。
5. マップ節には距離だけでなく到達時間を足す。
6. 外部レビュアーへの最重要質問として、以下を冒頭に追加する。
