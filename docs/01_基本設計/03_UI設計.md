# UI設計

## 画面構成

```
[ホーム画面] → [キャラピック画面] → [ゲーム画面] → [リザルト画面]
                                                         ↓
                                                   [ホーム画面へ戻る]
```

---

## 共通要素

### 右タブ：フレンド欄

全画面共通で画面右端にフレンド欄タブを表示する。

```
┌──────────────────────────┬──────────┐
│                          │ フレンド  │
│        メイン画面         │ ──────── │
│                          │ ● 山田   │
│                          │ ○ 鈴木   │
│                          │ ● 田中   │
└──────────────────────────┴──────────┘
```

| 要素 | 内容 |
|---|---|
| フレンド一覧 | オンライン/オフラインのステータス表示 |
| タブ開閉 | クリックで展開・折りたたみ |

---

## 1. ホーム画面

メインメニュー。上部ナビゲーションタブでセクションを切り替える構成。

```
┌────────────────────────────────────────────┬──────────┐
│ [ロゴ] [ゲーム] [所持品] [ガチャ]  [設定][通知] │ フレンド │
│ ────────────────────────────────────────── │          │
│                                            │          │
│               [ゲームアイコン]              │          │
│                  （中央）                   │          │
│                                            │          │
│                                            │          │
│              ┌──────────┐                  │          │
│              │ プレイ開始 │  ← 下部中央      │          │
│              └──────────┘                  │          │
└────────────────────────────────────────────┴──────────┘
```

| 要素 | 内容 |
|---|---|
| **タブ：ゲーム** | デフォルト表示。ゲームアイコン＋プレイ開始ボタン |
| **タブ：所持品** | 所持キャラクター・アイテム・スキンの一覧 |
| **タブ：ガチャ** | キャラクター・スキンを獲得するガチャメニュー |
| **ゲームアイコン** | ゲームタブ時に画面中央に表示 |
| **プレイ開始** | マッチメイキングを開始するメインボタン。画面下部中央に配置 |

---

## 2. キャラピック画面

マッチが成立した後、試合開始前にキャラクターを選択する画面。

```
┌────────────────────────────────────────┬──────────┐
│  味方チーム [3枠]     敵チーム [3枠]     │ フレンド │
│ ────────────────────────────────────── │          │
│                                        │          │
│  [キャラ1][キャラ2][キャラ3]...          │          │
│         ← キャラクター一覧 →            │          │
│                                        │          │
│  [選択中キャラ詳細]        [ピック確定]  │          │
└────────────────────────────────────────┴──────────┘
```

| 要素 | 内容 |
|---|---|
| チーム枠 | 味方・敵それぞれのピック状況を表示（各3枠） |
| キャラクター一覧 | 全キャラをロール別にフィルタリング可能 |
| キャラ詳細 | スキル概要・ステータスを表示 |
| ピック確定 | 制限時間内に確定。時間切れで自動選択 |

## 3. ゲーム画面（HUD）

```
┌──────────────────────────────────────────────────┐
│  [タイマー]   [スコア 0 - 0]   [オブジェクト状態]   │
│                                                  │
│                   3D ゲームビュー                  │
│                                                  │
│  [ミニマップ]              [キル通知]  [レベル/XP]  │
│  ──────────────────────────────────────────────  │
│  [HP][MP]  [Q][W][E][R CD表示]  [アイテム×6]  [金] │
└──────────────────────────────────────────────────┘
```

| 要素 | 内容 |
|---|---|
| **タイマー** | 試合経過時間（上部中央） |
| **スコア** | 両チームのキル数（上部中央） |
| **オブジェクト状態** | 中央オブジェクトのリスポーンタイマー（上部） |
| **ミニマップ** | 左下。ワールド座標をミニマップに変換表示 |
| **HP/MP バー** | 下部左。自キャラのリソース表示 |
| **スキル UI** | 下部中央。Q/W/E/R のアイコン＋クールダウンオーバーレイ＋残秒数 |
| **アイテムスロット** | 下部右。6枠 |
| **所持金** | 下部右端 |
| **キル通知** | 右上にフィード表示 |
| **ターゲット HP バー** | ターゲットキャラ上部にワールド空間で表示 |

## 4. リザルト画面

試合終了後に表示される結果画面。

```
┌────────────────────────────────────────┬──────────┐
│     VICTORY / DEFEAT                   │ フレンド │
│                                        │          │
│  [MVP 表示]                             │          │
│                                        │          │
│  プレイヤー別スタッツ一覧               │          │
│  （キル / デス / アシスト / ダメージ）   │          │
│                                        │          │
│  [ホームへ戻る]    [もう一度プレイ]     │          │
└────────────────────────────────────────┴──────────┘
```

| 要素 | 内容 |
|---|---|
| **勝敗表示** | VICTORY / DEFEAT を大きく表示 |
| **MVP** | 試合内で最も活躍したプレイヤーをハイライト |
| **スタッツ一覧** | 全6プレイヤーの KDA・ダメージ・ゴールドを表示 |
| **ホームへ戻る** | ホーム画面へ遷移 |
| **もう一度プレイ** | 即座にマッチメイキングを開始 |
