## 2. ゲームコンセプト

**Enigma** は、アニメ調ビジュアルで描く Fantasy × SF 近未来の世界を舞台にした 3D MOBA ゲームである。

廃墟となった古代遺跡と高層ビルが混在する近未来都市を戦場に、5v5 のチームが中央ジャングルのオブジェクトを争奪しながら敵拠点の破壊を目指す。

### コアコンセプト

本作の差別化軸は **「2層の回避体験」** にある。

| 層 | 体験 | 参考 |
|---|---|---|
| **第1層: AoE予告回避** | スキル発動時に地面へ予告エフェクト（インジケーター）が表示され、プレイヤーはそのエリアを視認して脱出する | FF14 的な「見てから避ける」体験 |
| **第2層: モーション予測回避** | 予告なしに放たれる攻撃に対し、敵のモーション・予備動作を読んで先行回避する | LoL 的な「読んで避ける」体験 |

この 2 層が共存することで、「視認して反応できる初心者の成功体験」と「モーションを読み切る上級者の熟練体験」が同じゲームの中に成立し、プレイヤーの習熟度に応じた奥行きを生む。

### 勝敗の鍵：中央オブジェクト争奪

マップ中央に配置された強力なモンスター（オブジェクト）を倒したチームは、試合を左右するチームバフを獲得する。個人のキルスコアよりもオブジェクト管理が勝敗を直接決定づけるため、チームの連携と判断力が問われる。

## 3. ジャンル・視点

| 項目 | 内容 |

## 4. ターゲットプレイヤー

| セグメント | 詳細 |
|---|---|
| **コアターゲット** | Smite・Paladins などの TPS MOBA 経験者。アクション操作とチーム戦略の両方を楽しみたい層 |
| **セカンダリ** | 原神・ブルーアーカイブなどのアニメ調ゲームのビジュアルに親和性がある層。MOBA 未経験でも操作感で入りやすい |

## 6. ゲームループ

```
[ロビー・マッチメイキング]
        ↓
[キャラクターセレクト]
        ↓
[インゲーム]
  ├─ 序盤（0〜7分）  : レーン農民処理、ジャングル小キャンプ確保
  ├─ 中盤（7〜15分） : 中央オブジェクト争奪 → チームバフ獲得、タワー攻略
  └─ 終盤（15〜20分）: バフ優位を活かした拠点破壊、ファイナルプッシュ
        ↓
[リザルト（MVP・統計表示）]
        ↓
[ロビーへ戻る]
```

### 試合時間の設計意図

15〜20分という短めの試合時間は、カジュアル層・忙しいプレイヤーのセッションに合わせた設計である。中央オブジェクトの争奪サイクルを起点に試合テンポを速め、長期の膠着状態が生まれにくいゲームデザインを目指す。

## 7. 勝利条件・敗北条件

### 勝利条件

敵チームの**タイタン（拠点ボス）**を撃破する。

### マップ構造と攻略順

```
[タワー Tier1] → [タワー Tier2] → [タイタン]
     ↑ 2レーン（Top / Bot）それぞれに存在

         ↑ 中央ジャングル
    [中央オブジェクト] ← 争奪でチームバフ獲得
```

| 構造物 / オブジェクト | 役割 |
|---|---|
| タワー Tier1 | レーン前衛の防衛拠点 |
| タワー Tier2 | タイタン手前の防衛拠点 |
| タイタン | 最終目標。撃破した側の勝利 |
| 中央オブジェクト | 倒したチームが試合を左右するバフを獲得。一定時間後にリスポーン |

### 敗北条件

自チームのタイタンが撃破される、または**降参投票**が成立した場合。

## 8. 参考タイトルとの差別化

| タイトル | 参考にする要素 |
|---|---|
| **Smite** | TPS 視点 MOBA の基本設計 |
| **FF14** | AoE インジケーターによる「見てから避ける」体験 |
| **LoL / Dota2** | モーション読みによる「予測回避」体験、オブジェクト重視のゲームデザイン |
| **原神** | アニメ調 Fantasy × SF のビジュアルスタイル |

### 差別化ポイントまとめ

| ポイント | 内容 |
|---|---|
| **2層の回避体験** | AoE予告（FF14的）× モーション予測（LoL的）の共存。初心者から上級者まで同じゲームで異なる習熟度の楽しみ方ができる |
| **中央オブジェクト主軸** | キルよりオブジェクト管理が勝敗に直結。チーム戦略の比重が高い |
| **短試合サイクル** | 15〜20分設計で、従来 MOBA（30〜50分）より参入ハードルを下げる |
| **アニメ調ビジュアル** | 原神風のアニメ調 + HDRP によるリッチなライティングで、Fantasy × SF 近未来の世界観を表現 |
